# Global Market Monitor — work in progress

This is an incomplete foundation for the Financial Data Analytics Data Tracker project. It is not yet the submitted tracker or a live site. `metrics.py` computes the requested close-based changes, 52-week extremes and full-history annualized volatility. `tests/test_metrics.py` tests those calculations.

Run `python3 -m pytest -q` from this directory.

The assignment requires a public archive of source responses, ten items with two source-reported daily numeric values, a Python daily pipeline, issue updates, history, status, three browser pages, offline support, and seven separate successful run dates. These remain to be implemented and verified. A data provider must explicitly permit the required public archive and cover the requested instruments; Yahoo Finance states its information must not be redistributed. Do not publish restricted data or treat derived changes as a second source-reported value.
